# 今日要闻 · 只推新闻

简洁的新闻阅读网页:**主页按板块展示重要新闻,点进板块看全部**。
聚合**知乎日报头条 + 百度热搜 + 量子位 + 少数派**多源,
另有 **GitHub 热门** 板块(近 30 天新项目按 Star 排序,20 个,带 AI 中文一句话概括与详细介绍)。
**只推真实新闻**——营销号、标题党、问答闲聊、娱乐八卦被多层过滤(可开启 **DeepSeek AI 审查** 二次过滤),
按**重要度**自动排序,页面每 **10 分钟自动更新**。手机浏览器打开即可使用,响应式布局。

> 🛡 **隐私与安全**:本项目不内置任何 API Key。DeepSeek Key 由**每个部署者自行填写**,
> 仅保存在自己机器的 `server/data/settings.json`(已被 `.gitignore` 排除,不会提交到仓库)。
> 克隆本仓库后无需任何 Key 即可运行,未配置 Key 时自动使用启发式过滤,功能完整。

## 特性

- 📰 **多源聚合**:知乎日报头条(编辑精选)/ 百度热搜(全网实时热点)/ 量子位(AI科技前沿)/ 少数派(科技数码),四源去重合并
- 🗂 **板块分类**:时政 / 财经 / 科技 / 社会 / 国际 / 体育 六大板块,主页展示各板块重要新闻,点击进入板块页看全部
- ⭐ **GitHub 热门板块**:近 30 天创建的新项目按 Star 数排序,展示 20 个项目;每个项目配 **AI 中文一句话概括**(批量生成,7 天缓存),不用点开即可了解项目用途;点击项目进入 AI 详细介绍页(一句话定位 + 功能要点 + 技术栈),介绍末尾附 GitHub 原始项目链接
- 🤖 **AI 审查(可选)**:在设置中填入 DeepSeek API Key 并开启,由 AI 剔除无关新闻、不重要新闻与营销号,并给出分类与重要度重新排序;未配置时自动降级为启发式过滤,不影响使用
- 🚫 **垃圾内容启发式过滤**:
  1. **问答闲聊剔除**:「瞎扯/段子/为什么…/…吗?」等直接过滤
  2. **营销号/标题党剔除**:震惊、速看、万万没想到、必看、逆天…直接过滤
  3. **娱乐严格过滤**:绯闻/恋情/官宣/综艺/演唱会…直接剔除;娱乐圈大事件(去世/被查/判刑/偷税等)保留但降权
- ⏱ **时效性优先**:6 小时内 +10 分、12 小时内 +5 分、24 小时内 +2 分;**超过 72 小时的内容直接剔除**
- 🔄 **每 10 分钟自动更新**:静默刷新不打断阅读;切回页面立即同步;支持手动刷新
- 📱 **响应式**:手机单列、桌面双列,自动跟随系统深色模式

## 快速开始

```bash
npm install
npm start        # 生产模式: 构建产物 + API 聚合服务 → http://localhost:3001
```

开发模式(热更新):

```bash
npm run dev      # 后端聚合服务 (端口 3001)
npm run dev:web  # Vite 前端 (端口 5173, /api 已代理)
```

## 配置 AI 审查 (DeepSeek)

1. 打开网页 → 右上角 **⚙ 设置**
2. 填入 DeepSeek API Key(获取: platform.deepseek.com)
3. 开启「AI 审查」开关 → 选择**审查频率**(每 1/3/6/24 小时)→ 保存 → 点「测试连接」验证
4. 保存后立即生效(后端自动清缓存)

> 同一 Key 也用于 **GitHub 热门板块**:项目一句话概括(批量)与点击项目后的 AI 详细介绍,
> 两者均有 7 天持久化缓存,不会重复消耗。

**省 token 机制(增量审查)**:
- **判定库**:AI 对每条新闻标题的判定(保留/剔除/分类/重要度)缓存 48 小时,同一标题绝不重复审查
- **增量审查**:每次刷新只把"新出现的标题"发给 AI,旧标题直接复用判定 → 实际调用量 ≈ 新增新闻数,而非总条数
- **频率闸**:距上次调用不足设定小时数时暂缓调用,新标题先用启发式过滤兜底,到期自动补审
- 示例:设 3 小时频率时,一天最多 8 次调用,每次只审新增的十几条,实际日消耗通常低于 ¥0.1

说明:
- Key 仅保存在本机 `server/data/settings.json`,只用于调用 DeepSeek API
- **设置接口仅限本机访问**:手机等局域网设备只能看新闻,不能改配置
- 调用失败自动回退启发式过滤;关闭 AI 审查后启发式过滤仍正常工作

## 重要度评分(可解释)

```
无 AI: 总分 = 来源基础分(头条90 > 热搜55-61 > 量子位60 > 热榜45 > 少数派42 > 日报40)
             + 重大关键词分(突发/首次/央行… +4/词, 上限12)
             + 时效分(6h内+10 / 12h内+5 / 24h内+2 / 48h以上-5)
             - 娱乐豁免降权 8   (娱乐圈大事件)
             - 问答豁免降权 5   (头条带问号的重大新闻)
有 AI: 总分 = 启发式分 × 0.45 + AI重要度(1-10) × 5.5
```

服务端 5 分钟缓存上游数据(单飞锁防击穿),上游全挂回退旧缓存。

## 数据源与可达性说明

| 源 | 类型 | 说明 |
|---|---|---|
| 知乎日报头条 | JSON API | 编辑精选, 综合新闻主源 |
| 百度热搜 | JSON API | 全网实时热点, 严格过滤娱乐后使用 |
| 量子位 | RSS | AI/科技前沿, 时效性强 |
| 少数派 | RSS | 科技数码/效率生活 |
| GitHub 热门 | JSON API | 近 30 天创建的新项目按 Star 排序 (独立板块, 20 个) |

> 实测结论: 联合早报/BBC中文/NYT中文/DW/中央社等海外源在当前网络环境下不可达,
> 财新 RSS 域名无法解析, 澎湃/网易/IT之家/虎嗅等有反爬限制, 故采用以上可达的高质量组合。

## 开机自启动 (Windows)

已配置为**登录时自动启动** + **看门狗保活**(服务崩溃后 5 秒自动重启):

```
scripts/start-server.bat   # 启动脚本 (已运行时跳过 + watchdog 循环)
scripts/hidden-start.vbs   # 隐藏窗口启动器 (由系统调用)
scripts/install-autostart.ps1 # 任务计划程序注册脚本 (部分机器策略会拒绝, 已改用启动文件夹)
```

当前生效方式: `hidden-start.vbs` 已复制到系统「启动」文件夹
(`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\NewsApp.vbs`)。
**若服务消失, 重启电脑登录后会自动恢复。**

- **卸载自启**: 删除启动文件夹中的 `NewsApp.vbs` 即可

## 手机访问 (局域网)

手机与电脑连**同一 Wi-Fi**, 浏览器打开 `http://电脑IP:3001`。
查看电脑 IP: `ipconfig` 中 `IPv4 地址` (例如 `192.168.1.5`)。
